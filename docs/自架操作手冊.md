# Rakazo 自架操作手冊

> 平常只要記得一件事：**打開「Rakazo 自架」App。** 安裝、改設定、檢查問題、更新、備份都在裡面。

本手冊以「macOS + Docker + 官方 published images + Tailscale HTTPS」的自架方式為例。範例中的 `my-mac`、`tailxxxx`、`you@example.com` 請換成你自己的值。

---

## 一、建議的配置

| 項目 | 內容 |
|---|---|
| 主機 | 一台 macOS（Apple Silicon）並安裝 Docker Desktop 26+ |
| 網址 | `https://my-mac.tailxxxx.ts.net:5173`（只有你的 Tailscale 網路連得到） |
| 安裝位置 | `~/rakazo`（設定檔 `~/rakazo/.env`） |
| 版本 | `RAKAZO_IMAGE_TAG=edge`（只有按「更新」才換版）；想更穩可改成發行版號 |
| 帳號 | 用 `SIGNUP_ALLOWLIST` 限制只有你的 Email 能註冊 |
| 模型 | OpenRouter API Key |
| 連線應用 | Composio **Platform 專案金鑰**（`ak_` 開頭） |
| 寄信 | Gmail SMTP（應用程式密碼）或 Resend |
| 管理 App | `/Applications/Rakazo 自架.app`（原始碼 `~/rakazo/tools/RakazoServer/`） |

## 二、日常怎麼用

| 想做的事 | 去哪裡 |
|---|---|
| 看伺服器是不是正常 | App →「總覽」→「重新檢查」。每一項都有「怎麼處理」 |
| 改網址、註冊名單、金鑰、上傳上限 | App →「設定」→ 改完按「儲存並套用」（會自動備份 `.env`、同步 Tailscale、重啟） |
| 設定或更換寄信 | App →「設定」→「寄信」→「設定精靈…」 |
| 升級 Rakazo | App →「總覽」→「更新 Rakazo…」（會先備份資料庫） |
| 備份 | App →「總覽」→「備份資料庫」（存到 `~/rakazo/backups`） |
| 回報問題 | App →「總覽」→「最近的錯誤」或「產生診斷報告」，截圖給 Agent |
| 在新的 Mac 上安裝 | App →「安裝」，照 6 個步驟走 |

**從其他裝置連線**
- 瀏覽器：直接打開網址。
- 桌面 App：Cmd+Shift+K →「現有執行個體」→ 貼網址。**不要選「這台電腦」**（那會另外裝一套）。
- 手機 App：登入畫面「Use a custom server」，手機要開著 Tailscale。
- 讓 Bot 操作某台 Mac：在那台的桌面 App 連上並登入 →「設定 → 一般 → 電腦」→ 打開「Let bots use this computer」。

## 三、安裝流程（App「安裝」分頁的 6 步）

1. **檢查環境**：Docker 26+、Docker Compose、curl、OpenSSL、Tailscale。
2. **下載並準備**：`install-images.sh --prepare-only` 產生 `~/rakazo/.env`。
3. **網址**：`BETTER_AUTH_URL`、`WEB_ORIGIN`、`API_URL` 填同一個 HTTPS 網址；用獨立埠號（例如 `:5173`），再 `tailscale serve --bg --https=5173 http://127.0.0.1:5173`。不要對外開放 3100。
4. **金鑰**：OpenRouter、Composio（`ak_` 開頭，App 會先向 Composio 驗證）。
5. **第一個帳號**（二選一）：
   - 先設定寄信，再註冊並收驗證信；或
   - 不寄信：`SIGNUPS_ENABLED=false`，用官方 `bootstrap-owner` 建立擁有者帳號。
6. **啟動並健康檢查**。

## 四、常見卡點（以後不要再踩）

| # | 卡點 | 原因 | 解法／預防 |
|---|---|---|---|
| 1 | Bot 一直連錯電腦或連不上主機 | 兩台 Mac 都開著「Let bots use this computer」，或連線中斷 | 只在要操作的那台打開；連不上就關掉再打開一次 |
| 2 | 指令回報「Not allowed」但其實已經執行 | 連線不穩時回報不可靠 | 重試前先檢查狀態（`~/rakazo` 是否已存在），不要重複安裝 |
| 3 | Tailscale 根網址已被其他服務佔用 | 同一台機器已有 `tailscale serve` | 用獨立埠號（例如 `:5173`）；App 會擋掉被佔用的埠號 |
| 4 | 重啟後登不進去（`EMAIL_NOT_VERIFIED`） | 有 `SIGNUP_ALLOWLIST` 但沒設定寄信，驗證信寄不出去 | **先設定寄信再註冊**，或不寄信就用官方 `bootstrap-owner` |
| 5 | 「連線應用」全部不能用（Composio 401） | 填的是 Composio「Connect」頁的 `ck_` 個人金鑰 | 要用 **Platform → API Keys** 的 `ak_` 專案金鑰。App 會擋掉 `ck_` |
| 6 | Composio 新手引導要你裝 skill | 那是給寫程式的 AI 工具用的 | 直接跳過，Rakazo 只需要 API Key |
| 7 | 桌面 App 三個選項分不清 | 「這台電腦」會用 Docker 另裝一套（45173 埠） | 自架版一律選「現有執行個體」 |
| 8 | 不知道 Gmail 地址要填誰 | 欄位是「寄件」帳號 | 寄件和收件可以是同一個 Gmail；Workspace 帳號可能被管理員關掉應用程式密碼 |
| 9 | 改 `.env` 沒生效 | `.env` 改完要重啟 | 用 App「儲存並套用」，會自動重啟 |
| 10 | 桌面 App 還連著雲端版 | 設定時按到雲端版 | Cmd+Shift+K 改成現有執行個體 |

## 五、跟官方文件對照

依據：[自架總覽](https://rakazo.com/docs/self-host)、[帳號與登入](https://rakazo.com/docs/self-host-accounts)、[客戶端](https://rakazo.com/docs/self-host-clients)、[升級](https://rakazo.com/docs/self-host-upgrading)、[備份](https://rakazo.com/docs/self-host-backups)、[整合](https://rakazo.com/docs/self-host-integrations)、[桌面 App](https://rakazo.com/docs/desktop-app)。

| 項目 | 本手冊做法 | 官方 | 結果 |
|---|---|---|---|
| 安裝方式 | `install-images.sh --prepare-only` → 改 `.env` → 再跑一次 | 同 | ✅ 一致 |
| 需求 | Docker 26+、Compose、curl、OpenSSL | 同 | ✅ |
| 網址 | `BETTER_AUTH_URL`＝`WEB_ORIGIN`＝`API_URL`＝同一個 HTTPS 網址，`RAKAZO_HOST`＝主機名 | 同 | ✅ |
| HTTPS | `tailscale serve` 轉送到 `127.0.0.1:5173` | 「在主機上終結 TLS 再轉送」；客戶端文件推薦 Tailscale 或 HTTPS 反向代理 | ✅ 符合原則 |
| 不開放 3100 | 只轉送 5173 | 同 | ✅ |
| 其他主機名 | 需要時填 `RAKAZO_ALLOWED_HOSTS` | 同 | ✅ |
| 第一個帳號 | 先寄信再註冊，或 `SIGNUPS_ENABLED=false` + `bootstrap-owner` | 同 | ✅（不要直接改資料庫） |
| 寄信 | `SMTP_URL=smtps://…@smtp.gmail.com:465` + `EMAIL_FROM` | `smtps://` 為隱含 TLS；Resend 用 `EMAIL_PROVIDER=resend` | ✅ |
| 版本 | `edge` | 範例預設 `edge` | ✅ 可用；想更穩可改成發行版號 |
| 升級 | `docker compose pull` → `up -d --wait` | 同樣模式 | ✅ |
| 備份 | `pg_dump -Fc` + 複製 `.env` | 官方腳本只給原始碼版／production 版 | ⚠️ 自訂做法；**不含 Bot 電腦檔案**。`.env` 裡的 `ENCRYPTION_KEY` 一定要跟資料庫一起保存 |
| 桌面 App「這台電腦」 | 不用 | 用 45173 埠另裝一套 | ✅ |
| Passkey | 不用 | 桌面 App 對自架伺服器會隱藏 passkey | ℹ️ 用密碼登入 |
| Composio | `COMPOSIO_API_KEY` 用 `ak_` | 文件只寫要設 `COMPOSIO_API_KEY` | ℹ️ `ak_`／`ck_` 差異是實際踩到的 |

## 六、疑難排解速查

| 症狀 | 先看 | 通常的解法 |
|---|---|---|
| 網頁打不開 | 總覽：Docker、服務、本機網頁、Tailscale | 打開 Docker →「啟動／重啟」→ 設定頁「立即同步」 |
| 登入說 Email 未驗證 | 寄信是否設定 | 設定寄信後用「忘記密碼」或重寄驗證信 |
| 連線應用不能用 | 總覽：Composio 那一項 | 換 `ak_` 金鑰 |
| Bot 不回話 | 總覽：OpenRouter 那一項 | 換金鑰，或到網頁「設定 → 模型」 |
| 收不到信 | 寄信精靈的測試信 | Gmail 要用應用程式密碼；改過 Google 密碼要重設 |
| 其他 | 「最近的錯誤」「產生診斷報告」 | 截圖給 Agent（不含金鑰） |

## 七、檔案位置

- 設定：`~/rakazo/.env`（每次 App 儲存前自動備份成 `.env.bak-日期時間`）
- 備份：`~/rakazo/backups/`
- 診斷報告：`~/rakazo/diagnostics/`
- App 原始碼：`~/rakazo/tools/RakazoServer/`（重新編譯：`./build.sh`）
